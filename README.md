# CampusPe Landing Page

A pixel-accurate, fully responsive implementation of the CampusPe landing page built with **Next.js 16**, **React 19**, and **Tailwind CSS 4**.

## 🚀 Live Demo

- **Live URL:** [https://campus-pe-lovat.vercel.app/](https://campus-pe-lovat.vercel.app/)
- **GitHub Repository:** [https://github.com/PrabhavRathi06/campus_pe](https://github.com/PrabhavRathi06/campus_pe)

## 🛠 Tech Stack

- **Next.js 16** (App Router & Turbopack)
- **React 19**
- **TypeScript**
- **Tailwind CSS 4**

## ✨ Features & Implemented Sections

- ✅ **Pixel-Accurate Design**: Faithfully reproduced from Figma.
- ✅ **Fully Responsive**: Mobile-first design for smartphones, tablets, and wide screens.
- ✅ **Interactive CTAs**: Smooth hover, active, focus, and micro-interaction states across all buttons and inputs.
- ✅ **Hero Section**: Floating notification cards (WhatsApp Alert, AI Campus Assistant, Resume Builder) with CSS floating animations.
- ✅ **Service Cards**: College, Job Seeker, and Recruiter cards with vector illustrations.
- ✅ **Platform Stats**: Verified metrics with animated badge icons.
- ✅ **Partner Showcase**: Trusted partner badges across India.
- ✅ **Opportunity Discovery**: Interactive filter tabs for colleges, jobs, and internships.
- ✅ **Resume Upload**: Functional drag-and-drop file upload simulator with real-time feedback.
- ✅ **Targeted User Sections**: Dedicated feature breakdowns for both Colleges and Employers.
- ✅ **Interactive App Showcase**: 5-screen interactive device carousel.
- ✅ **Download Section**: Native App Store & Google Play download badges with dual 3D phone presentation.
- ✅ **Comprehensive Footer**: Full directory navigation, legal policies, contact strip, and social channels.

## 📁 Project Structure

```
src/

```
